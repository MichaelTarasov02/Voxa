# Security reports

Don't post API keys, personal recordings or vulnerability details in a public issue.

Use this repository's **Security → Report a vulnerability** feature to send a private report. Include the affected Voxa version, operating system and minimal reproduction steps using invented text rather than private data.

If you exposed an API key, revoke it in your OpenAI account and create a replacement. Deleting a GitHub comment alone does not revoke the key.

These are beta releases. There is no guaranteed security-response timeframe. Download only release assets from this repository and check their SHA-256 checksums.

Not sure whether something is a security problem? You can use a private report for that too. Describe what you saw and why it concerns you; you don't need to send a real key or a recording to demonstrate it. Please leave out anything we wouldn't need to reproduce the problem on a separate test account.
