# Voxa — установка и первый запуск

Voxa превращает речь в текст и помогает переводить его прямо во время работы. Нужен ваш собственный OpenAI API key. Распознавание работает через интернет, не локально на устройстве.

## Скачать

- **[Для Mac](https://github.com/MichaelTarasov02/Voxa/releases/download/v0.1.1/Voxa-0.1.1-universal.dmg)** — macOS 14+, Apple Silicon и Intel.
- **[Для Windows](https://github.com/MichaelTarasov02/Voxa/releases/download/v0.2.0-windows-beta.1/Voxa-0.2.0-Windows-x64-Setup.exe)** — Windows 11 x64. Отдельно устанавливать .NET не нужно.

Обе версии пока в бете. Mac-сборка не нотарифицирована Apple, Windows-установщик не имеет цифровой подписи. Проверяйте источник и контрольную сумму из соответствующего релиза. Не отключайте защиту компьютера. Если установка заблокирована политикой вашей организации, обратитесь к администратору.

## Четыре шага

1. На Mac откройте DMG и перетащите Voxa в Applications. На Windows запустите установщик.
2. Добавьте свой ключ в настройках Voxa. Его можно создать в [OpenAI API](https://platform.openai.com/api-keys). Подписка ChatGPT не оплачивает API: для него нужны отдельный биллинг и доступ к используемым моделям.
3. Разрешите доступ к микрофону. На Mac дополнительно нужен Accessibility. На Windows включите доступ к микрофону для классических приложений в Settings → Privacy & security → Microphone.
4. Поставьте курсор в текстовое поле, включите диктовку, произнесите короткую фразу и завершите запись тем же сочетанием.

Для первой пробы можно сказать: «Привет, давай созвонимся завтра в десять». Сначала проверьте, что фраза попала в нужное поле. Потом попробуйте режим с переводом. Так проще понять, всё ли работает, до того как вы начнёте диктовать длинное письмо. Если текст не появился, загляните в историю: там может быть готовый ответ или запись с ошибкой. Не спешите говорить всё заново.

| Действие | Mac | Windows |
| --- | --- | --- |
| Начать / завершить диктовку | Fn | Ctrl + Alt + D |
| Диктовать с переводом на английский | Shift + Fn | Ctrl + Alt + Shift + D |
| Перевести выделенный текст на русский | Control + Fn | Ctrl + Alt + R |
| Отменить запись / закрыть перевод | Escape | Escape |

Перевод выделенного текста появляется в нижней панели, а не вставляется в исходное поле. Он закрывается через 10 секунд или по Escape. В Windows есть пауза и продолжение записи. Сочетания клавиш и язык интерфейса можно изменить в настройках.

## Важно знать

Ключ хранится в Keychain на Mac или Credential Manager на Windows. Аудио и текст отправляются в OpenAI для обработки. История и записи находятся на вашем устройстве, но Voxa не шифрует эти файлы отдельно. [Подробнее о данных](PRIVACY.md).

Если обработка завершилась ошибкой, найдите запись в истории и повторите запрос. Если текст не вставился в нужное приложение, скопируйте результат из истории. Проверяйте имена, числа и смысл перед отправкой.

На Windows закрытие основного окна не выключает Voxa: приложение остаётся в трее. Для выхода выберите Quit. Расходы в приложении приблизительные, итоговые начисления смотрите в OpenAI. Возможности двух платформ пока различаются; подробнее — в [основном README](README.md).
