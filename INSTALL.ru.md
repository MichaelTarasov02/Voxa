# Voxa — установка и первый запуск

Voxa превращает речь в текст и помогает переводить его прямо во время работы. Нужен ваш собственный OpenAI API key. Распознавание работает через интернет, не локально на устройстве.

## Скачать

- **[Для Mac — 0.3.1 beta](https://github.com/MichaelTarasov02/Voxa/releases/download/v0.3.1-macos-beta.1/Voxa-0.3.1-universal.dmg)** — macOS 14+, Apple Silicon и Intel.
- **[Для Windows — 0.2.1 beta](https://github.com/MichaelTarasov02/Voxa/releases/download/v0.2.1-windows-beta.1/Voxa-0.2.1-Windows-x64-Setup.exe)** — Windows 11 x64. Отдельно устанавливать .NET не нужно.

Обе версии пока в бете. Mac-сборка не нотарифицирована Apple, Windows-установщик не имеет цифровой подписи. Проверяйте источник и контрольную сумму из соответствующего релиза. Не отключайте защиту компьютера. Если установка заблокирована политикой вашей организации, обратитесь к администратору.

## Четыре шага

1. На Mac откройте DMG и перетащите Voxa в Applications. На Windows запустите установщик.
2. Добавьте свой ключ в настройках Voxa. Его можно создать в [OpenAI API](https://platform.openai.com/api-keys). Подписка ChatGPT не оплачивает API: для него нужны отдельный биллинг и доступ к используемым моделям.
3. Разрешите доступ к микрофону. На Mac дополнительно нужен Accessibility. На Windows включите доступ к микрофону для классических приложений в Settings → Privacy & security → Microphone.
4. Поставьте курсор в текстовое поле, включите диктовку, произнесите короткую фразу и завершите запись тем же сочетанием.

Для первой пробы можно сказать: «Привет, давай созвонимся завтра в десять». Сначала проверьте, что фраза попала в нужное поле. Потом попробуйте режим с переводом. Так проще понять, всё ли работает, до того как вы начнёте диктовать длинное письмо. Если текст не появился, загляните в историю: там может быть готовый ответ или запись с ошибкой. Не спешите говорить всё заново.

| Действие | Mac | Windows |
| --- | --- | --- |
| Начать / завершить диктовку | Fn | Ctrl + Alt + D |
| Диктовать с переводом (на Mac язык выбирается; по умолчанию американский английский) | Shift + Fn | Ctrl + Alt + Shift + D |
| Перевести выделенный текст (на Mac на выбранный язык) | Control + Fn | Ctrl + Alt + R |
| Отменить запись / закрыть перевод | Escape | Escape |

Перевод выделенного текста появляется в нижней панели, а не вставляется в исходное поле. На Mac он остаётся открытым под курсором; после ухода курсора начинается новый отсчёт 10 секунд. В Windows перевод закрывается через 10 секунд. Escape закрывает панель сразу. На обеих платформах есть пауза записи. Сочетания клавиш и язык интерфейса можно изменить в настройках.

## Что нового

На Mac диктовка с переводом, перевод выделенного текста и переводчик в приложении имеют отдельные целевые языки. В сетапе можно включить персонализацию распознавания: после подтверждённой вставки исправленное имя или термин сохраняется автоматически, с возможностью отмены. В Dictionary можно посмотреть и удалить варианты написания. До 12 сохранённых написаний могут передаваться OpenAI как подсказка при диктовке с явно выбранным русским или английским языком; при Auto аудиоподсказка не отправляется. Функцию можно выключить в настройках.

На Windows появилась базовая вкладка Translation: введите текст, выберите язык и нажмите Translate или Ctrl + Enter. Американский английский выбран по умолчанию. История переводов, автоперевод, обучение словаря и новые метрики Mac в этот Windows-релиз не входят.

Для обновления закройте Voxa и замените приложение в Applications на Mac либо запустите новый установщик на Windows. История, настройки и ключ сохраняются. На Mac после замены может понадобиться повторно включить разрешения. Ранее неучтённые расходы переводчика восстановить нельзя.

Перед выходом из старой версии сохраните текст, который ещё открыт в переводчике: черновик может не пережить перезапуск. Саму папку с данными удалять не нужно. Если после обновления вы видите старый экран, выйдите из Voxa через Quit и откройте её из Applications на Mac или из меню «Пуск» на Windows.

## Важно знать

Ключ хранится в Keychain на Mac или Credential Manager на Windows. Аудио и текст отправляются в OpenAI для обработки. История и записи находятся на вашем устройстве, но Voxa не шифрует эти файлы отдельно. [Подробнее о данных](PRIVACY.md).

Если обработка завершилась ошибкой, найдите запись в истории и повторите запрос. Если текст не вставился в нужное приложение, скопируйте результат из истории. Проверяйте имена, числа и смысл перед отправкой.

На Windows закрытие основного окна не выключает Voxa: приложение остаётся в трее. Для выхода выберите Quit. Расходы в приложении приблизительные, итоговые начисления смотрите в OpenAI. Возможности двух платформ пока различаются; подробнее — в [основном README](README.md).
